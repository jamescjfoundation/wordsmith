Wordsmith is a family of free, open-source apps for writers. Each app does one kind of writing
well, and they hand work to each other. This wiki explains how to use them, from your first page
to a finished book.

## About this wiki

Each app's pages here are that app's own guide. The guide is kept with the app's code, so it
changes with the app, and this wiki is built from it. Every page has an **Edit on GitHub** link at
the bottom, which opens the file the page is made from. If something is wrong, unclear or missing,
that's the quickest way to fix it, or see [Getting help](./start/help.mdx).

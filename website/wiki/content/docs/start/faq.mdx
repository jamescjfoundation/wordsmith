<Accordions type="multiple">
<Accordion title="Is Wordsmith really free?">
Yes. All three apps are free to download, use, study and change, with no account, subscription or
paid tier. The code is open source under the MIT license or the Apache License 2.0. Wordsmith is
made by Wordsmith & Ink, a project of The James C. J. Foundation.
</Accordion>

<Accordion title="When can I download an installer?">
Installers for macOS, Windows and Linux come with each app's first release. Until then you can
build any app from its source code; [Installing](./install.mdx) shows how. Watch the app's GitHub
repository to hear about releases.
</Accordion>

<Accordion title="Which app should I use?">
Script for screenplays, TV episodes and stage plays. Manuscript for novels and other long work.
Book to turn a finished manuscript into a print book and an ebook, once it's ready. See
[The Wordsmith apps](./index.mdx).
</Accordion>

<Accordion title="Do I need to be online?">
No. The apps work entirely on your computer. The only time one goes online by itself is to check
for updates, and you can turn that off. See [Privacy](./privacy.mdx).
</Accordion>

<Accordion title="Is my writing sent anywhere?">
No. There's no account, no cloud and no telemetry. Your writing is saved in files on your
computer, and you decide where they go.
</Accordion>

<Accordion title="Can I open my work in other apps?">
Yes. Script saves plain text and also opens and exports Fountain files. Manuscript keeps each scene
as a Markdown file and can export to common formats. See [Your files](./files.mdx) and each app's
import and export pages.
</Accordion>

<Accordion title="Which systems does it run on?">
macOS (11 or later), Windows and Linux.
</Accordion>

<Accordion title="Which languages does it speak?">
Manuscript's interface is in English and Spanish. The other apps are in English for now. Help with
translations is welcome; see [Getting help and helping out](./help.mdx).
</Accordion>

<Accordion title="I found a bug. What should I do?">
Open an issue in the app's GitHub repository; [Getting help and helping out](./help.mdx) lists them
and says what to include.
</Accordion>
</Accordions>

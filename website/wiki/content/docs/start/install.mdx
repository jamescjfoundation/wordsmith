Each app is one free download. There is no account to make. All three run on:

- **macOS**, on a Mac with Apple silicon;
- **Windows**, 64-bit (x64);
- **Linux**, 64-bit (x86_64).

## Or let the launcher do it

The Wordsmith Launcher is a small program that downloads the apps you choose, checks each
download against the release's list of checksums, installs it for your account, and later
updates it. It is a download of its own, from the same kind of releases page:

<Downloads app="launcher" />

[Installing and updating the launcher](../launcher/installing.mdx) has its steps, and
[The apps](../launcher/apps.mdx) says where it puts each app. You do not need the launcher: the
downloads above work by themselves.

## Open it the first time

The apps are not signed with a paid developer certificate, so macOS and Windows stop to ask before
they open one for the first time. That is expected. You do this once per app.

<Tabs items={['macOS', 'Windows', 'Linux']}>
  <Tab value="macOS">
    1. Open the file you downloaded and move the app to your **Applications** folder.
    2. Open the app. macOS says it cannot check the app. Close the notice.
    3. Open **System Settings**, choose **Privacy & Security**, and scroll down to **Security**.
    4. Beside the app's name, click **Open Anyway**, and confirm.

    On macOS 14 and earlier you can also hold Control, click the app, choose **Open**, and then
    **Open** again.
  </Tab>
  <Tab value="Windows">
    1. Unpack the file you downloaded, or run it if it is an installer.
    2. Start the app. Windows may show **Windows protected your PC**.
    3. Click **More info**, then **Run anyway**.
  </Tab>
  <Tab value="Linux">
    Unpack the file you downloaded and start the program inside it. Linux does not ask.
  </Tab>
</Tabs>

## Updates

When an app starts, it asks GitHub whether a newer version has been published. When there is one,
it tells you. Where the app can replace itself it offers to install the update; otherwise it opens
the release's page for you to download it. Nothing is downloaded unless you choose to.

To turn the check off, open **File › Preferences** and clear
**Check for updates when the app starts**. You can still check by hand. [Privacy](./privacy.mdx)
says exactly what the check sends.

## Build an app yourself

Every app is open source, and you can build it from its code. You need
[Git](https://git-scm.com) and [Rust](https://rustup.rs); each app asks for the Rust version it
was made with, and rustup fetches it. The first build takes a few minutes and needs an internet
connection. Each repository's README has the commands:

- [Wordsmith Script](https://github.com/jamescjfoundation/wordsmith-script#readme)
- [Wordsmith Manuscript](https://github.com/jamescjfoundation/wordsmith-manuscript#readme)
- [Wordsmith Book](https://github.com/jamescjfoundation/wordsmith-book#readme)

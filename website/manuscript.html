The whole novel, in one place.

A free, open-source app for writing novels and other long work. Plan on a corkboard, draft in a binder of chapters and scenes, keep your story bible beside the text, and hand the finished manuscript to Wordsmith Book.

What it does

Plan it, write it, revise it, finish it.

The binder

Parts, chapters and scenes in one list. Drag to reorder, split and merge, and read any run of scenes as one continuous text.

Corkboard and outline

Index cards for every scene, a freeform board with lines between ideas, and an outline with your own columns.

Story bible

Characters, places and anything else, with your own templates, relationships read from both sides, and suggested links from the names in a scene.

Drafts

Keep the manuscript as it is and start a new draft. Compare drafts chapter by chapter and choose which one goes to print.

Snapshots

Save a scene before a big change and compare it word by word later. Restore it in one click.

Targets and history

Word targets for the session and the book, a writing calendar kept on your computer, and progress you can see.

Threads and timeline

Lanes for plot threads or points of view, and a timeline of the story's own dates.

Series

Several books can share one story bible, so what you learn about a character in book one is there in book three.

Revision tools

Split the editor, leave comments, mark revision passes in color, and turn on offline grammar hints if you want them.

Planning

See the shape of the story.

Every scene is a card. Write a line on it, color it by thread or point of view, and move it around until the story works. The text moves with it.

Your words, safe

Bring everything in. Lose nothing.

Import from Word, OpenDocument, RTF, Markdown, web pages, EPUB and plain text, or a whole folder of documents at once. Chapters and scene breaks are found for you, and every import is checked word for word against the source. If a single word doesn't match, the import isn't made.

  • A project is a folder of plain text files, readable in any text editor
  • One file per scene, so version control and synced folders work well
  • Export a standard manuscript for agents and editors, as DOCX or PDF
  • Export to Word, OpenDocument, RTF, Markdown, HTML and EPUB, each one checked
  • Hand the book to Wordsmith Book as one package, ready to typeset
  • Keep Wordsmith Script screenplays inside the same project

Finished? Make it a book.

Wordsmith Book opens your Manuscript project directly and typesets it for print and ebook. If it spots a typo, it offers the fix back instead of changing your words.

Try it today

Build it from source.

There are no installers yet. With Rust installed you can run the current version now. The interface is in English and Spanish so far, and more languages can be added.

Terminal
git clone https://github.com/jamescjfoundation/wordsmith-manuscript
cd wordsmith-manuscript
cargo run -p wordsmith-manuscript

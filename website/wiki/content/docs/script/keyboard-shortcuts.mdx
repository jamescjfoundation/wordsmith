**Mod** is <Kbd>Cmd</Kbd> on macOS and <Kbd>Ctrl</Kbd> on Windows and Linux.
**Alt** is <Kbd>Option</Kbd> on a Mac. **Return** is the key marked Enter on
some keyboards.

<Callout type="info" title="Make your own keys">
**Keys** on the File page lists every command with its key. **Set…** waits for
the key you press, and **Reset** puts the command's key back. Your keys are kept
with your preferences. Custom elements and macros can have keys of their own,
set in Element Settings and the macro window.
</Callout>

Any command can also be found by name in the command search box
(<Kbd>Mod</Kbd>+<Kbd>Shift</Kbd>+<Kbd>P</Kbd>), and the whole ribbon can be used
from the keyboard with key tips (<Kbd>F10</Kbd>); see
[The window](./the-window.mdx#using-the-ribbon-from-the-keyboard).

## Macros

New scripts come with ten macros on <Kbd>Mod</Kbd>+<Kbd>Alt</Kbd>+<Kbd>Shift</Kbd>
and a digit (1 INT., 2 EXT., 3 DAY, 4 NIGHT, 5 CONTINUOUS, 6 and 7
parentheticals, 8 CUT TO:, 9 DISSOLVE TO:, 0 FADE OUT.). See
[Writing](./writing.mdx#macros) to change them.

## In lists and views

| Where | Keys |
| --- | --- |
| Autocomplete list | <Kbd>Tab</Kbd> or <Kbd>Return</Kbd> takes a match, <Kbd>Up</Kbd> and <Kbd>Down</Kbd> move, <Kbd>Escape</Kbd> hides it |
| Index cards, scene view, story board, outline | <Kbd>Escape</Kbd> goes back to the script |
| Beat window | <Kbd>Tab</Kbd> moves between the title and the body |
| Reformat | a digit sets the element, <Kbd>D</Kbd> deletes the paragraph, arrow keys move |
| File page | <Kbd>Escape</Kbd> goes back to the script |

# Decisions

Decisions about Wordsmith Launcher, one file each (`NNNN-title.md`): context, decision,
consequences, and when to revisit. Decisions about shared interfaces, upstream and tooling go in
open-source-core's `docs/decisions/`; decisions that hold across the Wordsmith repositories go in
[`project/decisions/`](https://github.com/jamescjfoundation/wordsmith/blob/main/project/decisions/README.md) at the top of this repository. From
outside this folder a record here is cited as "Launcher decision 0002".

Each record's first line gives its date and status. A record is amended with a dated line or
section; its reasoning is never rewritten. A record that no longer holds says which record
replaced it.

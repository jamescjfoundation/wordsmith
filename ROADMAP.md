# Roadmap

What is planned for this repository is kept as issues, not in a file.

**The [v1 milestone](https://github.com/jamescjfoundation/wordsmith/milestone/1)** holds what the website, the wiki, the brand kit, the project map and the launcher need before the Wordsmith apps reach 1.0 and the project is made public. Work that is found goes in as an issue with that milestone; work that is done is closed there. This file holds no list of its own, so it cannot fall behind.

The goal it serves: Wordsmith Script, Wordsmith Manuscript and Wordsmith Book each at 1.0, first published as 0.9.0, a preview that tries the downloads and the updates; Wordsmith Launcher; and a website and a wiki that say truly what the apps do.

Each app keeps its own plan the same way, as issues in its repository: [Wordsmith Script](https://github.com/jamescjfoundation/wordsmith-script/issues), [Wordsmith Manuscript](https://github.com/jamescjfoundation/wordsmith-manuscript/issues), [Wordsmith Book](https://github.com/jamescjfoundation/wordsmith-book/issues), and the shared base, [open-source-core](https://github.com/jamescjfoundation/open-source-core/issues).

To add something: open an issue in this repository, and say what should be true when it is done. [`CONTRIBUTING.md`](CONTRIBUTING.md) has the rules.

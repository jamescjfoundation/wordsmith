Every book in Wordsmith Book has one **source**: the text it is made from. There are two kinds.

- **A linked Manuscript project.** Book reads a Wordsmith Manuscript project and never changes it.
  The writer keeps writing in Manuscript, and Book picks up the changes.
- **An owned source.** Book keeps its own copy of the text inside the book project. This is what
  you get when you import a Word file or another document.

## From Wordsmith Manuscript

<Status value="available" />

This is the smoothest way in. A book linked to a Manuscript project gets the parts, chapters,
scenes, front and back matter, notes and pictures exactly as the writer set them up, along with
the book's details: title, subtitle, author and pen name, series, language, description and
copyright.

- **Book never writes to the Manuscript project.** Everything Book adds (the design, editions,
  ISBNs, generated pages) is kept in the book project.
- **The writer's order is kept.** In Book's outline, the manuscript's own chapters and scenes are
  read-only and say "change this in Manuscript". You can still arrange the pages Book makes, like
  the title page and the copyright page.
- **Changes are noticed.** When the manuscript changes on disk, Book reads it again when you come
  back to the window. You can also choose **Read the Manuscript Again**.
- **A folder or a single file both work:** a project folder (`.wsm`) or a packed project
  (`.wsmz`). A packed project is a handy way to send a finished book to someone else.

In Manuscript, when the book is finished, you can make a packed copy for Book with
**Export › Book package**. It checks every word on the way out and tells you which details Book
will still need, such as ISBNs.

<Callout type="info">
  Book reads version 1 of Manuscript's book format, which Manuscript 0.1 and later write. If a
  project uses a version Book doesn't know, Book says so and names both versions instead of
  guessing.
</Callout>

## Fixing a typo

<Status value="available" />

Book is not the place to edit your book, but you will spot the odd typo while laying it out. Pick
a chapter in the outline and click **Fix** beside the paragraph. Change the words and choose
**Make Fix**.

- **In a book with an owned source,** the fix is made in the text, and you can undo it.
- **In a book linked to Manuscript,** the fix is not made in the manuscript. It is **offered** to
  the writer instead: Book adds it to a small file next to the Manuscript project, and Manuscript
  shows it in its "Offered fixes" list to accept or reject. While it waits, Book uses the fix in
  its own copy of the book.

If the writer rejects a fix, Book stops using it. If the words have changed since, the fix shows
as out of date with the new text. Book never overwrites the writer's words quietly.

## Importing a file

<Status value="in-progress" />

Book can bring in a book from:

- Word documents (DOCX), including ones downloaded from online word processors
- OpenDocument text (ODT)
- RTF
- Markdown
- Plain text

This works and is tested inside Book, and the **import review** screen is built. Starting an
import from the window still needs its "choose a file" step, which is coming.

When you import, Book looks for the book's shape and shows you what it found before anything is
made:

- **Chapters** from heading styles, "Chapter 1" or "Chapter One" lines, numbers on their own line,
  and short lines in capitals after a page break.
- **Parts** from "Part One" lines or a higher heading level.
- **Scene breaks** from lines of symbols such as `* * *` or `#`, or from blank lines when the file
  has no symbols.
- **Front and back matter** from titles like Dedication, Contents, Acknowledgements and About the
  Author.

Each rule can be switched off in the review if it guesses wrong, and your choices are kept with
the book.

Book keeps italic, bold, small caps, superscript, links, notes, pictures with their descriptions,
block quotes and verse. Underlining is offered as italic. It drops fonts, sizes, colors, manual
spacing, tab indents and empty paragraphs, and lists what it dropped. It never drops words.

Then it checks every word of the new book against your file. If a single word doesn't match, the
import is refused and you are shown where.

## Typographic cleanup

<Status value="available" />

Many manuscripts have straight quotes, double hyphens and three dots where a printed book has
curly quotes, dashes and an ellipsis. Book can tidy these up, but only with your say. Open the
**Cleanup** panel to see each proposed change with where it is:

- straight quotes to curly quotes, apostrophes included
- `--` to an em dash
- `...` to an ellipsis
- double spaces to one, and spaces at the end of a paragraph removed

Click **Show** to see a change in its sentence. Tick the ones you want and choose
**Make Chosen Changes**, or **Choose All** or **Choose None** first. **Undo Last Cleanup** puts
them back.

Cleanup never changes a letter, a digit or the order of your words. If you want the text left
alone, tick **Keep exactly as written** and Book proposes nothing.

Cleanup is only for a book's own source. A linked Manuscript project is never cleaned up by Book:
Manuscript already types curly quotes and dashes as you write.

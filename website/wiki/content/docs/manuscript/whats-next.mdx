Everything else in this section works today. The items on this page don't, yet. Plans can change.

## The first release

<Status value="in-progress" />

Version 1.0 is prepared and waiting to be published. When it is, you will be able to download
Manuscript from its GitHub releases for macOS, Windows and Linux, instead of building it yourself.
Each download will come with a way to check that it was built from the project's own source.

## System file dialogs

<Status value="planned" />

For now, you type a file's path when you open, import or export. The system's own Open and Save
dialogs are planned.

## A web version

<Status value="planned" />

Manuscript is set up for a version that runs in a web browser. It is waiting for the shared base
the Wordsmith apps are built on to support the web.

## Sharing a story bible with Wordsmith Script

<Status value="planned" />

A Manuscript series can already share one story bible between books. Sharing that bible with
Wordsmith Script projects, for example when you adapt your novel for the screen, is planned.

## Syncing between devices

<Status value="planned" />

Today a project is [safe in a synced folder](./files.mdx#synced-folders): changes made elsewhere
are read in, and nothing is written over without a copy. Merging changes from several devices
automatically, as you write, is planned for after 1.0.

## More interface languages

<Status value="planned" />

The interface is in English and Spanish. It is built so more languages can be added.

## What Manuscript won't do

Some things are deliberately left to other apps, or out:

- **Book design and typesetting** is Wordsmith Book's job. Manuscript makes a standard manuscript
  and a plain reading copy, and [hands the book to Wordsmith Book](./sending-to-book.mdx).
- **Writing screenplays** is Wordsmith Script's job. A project can hold screenplays, but Script
  edits them.
- **Accounts, a cloud service and telemetry** are not part of the plan. Your files stay yours.
- **AI writing features** are not planned. If any are ever added, they will be behind a setting
  that is off unless you turn it on.

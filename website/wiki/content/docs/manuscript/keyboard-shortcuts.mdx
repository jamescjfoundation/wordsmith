<Kbd>Mod</Kbd> means <Kbd>Ctrl</Kbd> on Windows and Linux, and <Kbd>Cmd</Kbd> on a Mac.

These are the default keys. You can change any of them, or give a key to a command that has
none, on File › Keys. Every command is also in the command palette
(<Kbd>Mod</Kbd>+<Kbd>Shift</Kbd>+<Kbd>P</Kbd>), so you can always find one by name.

## Projects and files

| Command | Key |
| --- | --- |
| New Project | <Kbd>Mod</Kbd>+<Kbd>N</Kbd> |
| Open Project | <Kbd>Mod</Kbd>+<Kbd>O</Kbd> |
| Save | <Kbd>Mod</Kbd>+<Kbd>S</Kbd> |
| Save As | <Kbd>Mod</Kbd>+<Kbd>Shift</Kbd>+<Kbd>S</Kbd> |
| Export | <Kbd>Mod</Kbd>+<Kbd>E</Kbd> |

## Key tips

Press <Kbd>F10</Kbd> to show a letter on each ribbon tab. Type a tab's letter, and each button on
that tab shows its own letters; type them to use the button, without the mouse.

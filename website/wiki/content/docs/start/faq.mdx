<Accordions type="multiple">
<Accordion title="Is Wordsmith really free?">
Yes. All three apps are free to download, use, study and change, with no account, subscription or
paid tier. The code is open source under the MIT license or the Apache License 2.0. Wordsmith is
made by Wordsmith & Ink, a project of The James C. J. Foundation.
</Accordion>

<Accordion title="Where do I download the apps?">
From each app's releases page on GitHub. [Installing](./install.mdx) lists the downloads for
macOS, Windows and Linux, and says how to open an app the first time.
</Accordion>

<Accordion title="Why does my computer warn me when I open an app?">
The apps are not signed with a paid developer certificate, so macOS and Windows ask before they
open one for the first time. [Installing](./install.mdx#open-it-the-first-time) has the steps.
You do it once per app.
</Accordion>

<Accordion title="Which app should I use?">
Script for screenplays, TV episodes and stage plays. Manuscript for novels and other long work.
Book to turn a finished manuscript into a print book and an ebook. See
[The Wordsmith apps](./index.mdx).
</Accordion>

<Accordion title="Do I need to be online?">
No. The apps work entirely on your computer. The only time one goes online by itself is to check
for updates, and you can turn that off. See [Privacy](./privacy.mdx).
</Accordion>

<Accordion title="Is my writing sent anywhere?">
No. There's no account, no cloud and no telemetry. Your writing is saved in files on your
computer, and you decide where they go.
</Accordion>

<Accordion title="Can I open my work in other apps?">
Yes. Script saves plain text and also opens and exports Fountain files. Manuscript keeps each
document as a Markdown file and exports to Word, OpenDocument, RTF, Markdown, HTML and EPUB. Book
makes a print PDF and an EPUB. See [Your files](./files.mdx) and each app's import and export
pages.
</Accordion>

<Accordion title="Which systems does it run on?">
macOS on a Mac with Apple silicon, 64-bit Windows and 64-bit Linux.
</Accordion>

<Accordion title="Which languages does it speak?">
Manuscript and Book come in English and Spanish, and follow your computer's language. Script is in
English. Help with translations is welcome; see [Getting help and helping out](./help.mdx).
</Accordion>

<Accordion title="What is planned?">
Each app's open issues on GitHub are its plan; [Getting help and helping out](./help.mdx) links to
them. The Wordsmith Launcher, one app to install and open the three, is planned and not started.
</Accordion>

<Accordion title="I found a bug. What should I do?">
Open an issue in the app's GitHub repository; [Getting help and helping out](./help.mdx) lists them
and says what to include.
</Accordion>
</Accordions>

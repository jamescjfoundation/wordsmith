Your writing is saved in ordinary files on your own computer. No app needs an account or a
server, and the files are yours to copy, back up and keep.

## What each app saves

| App | You save | What it is |
| --- | --- | --- |
| Wordsmith Script | `My Script.wss` | One plain-text file per script. Script also opens Fountain (`.fountain`) files. |
| Wordsmith Manuscript | `My Novel.wsm` | A project folder: one Markdown file per scene and per story-bible entry, plus the binder, notes and snapshots. |
| | `My Novel.wsmz` | The same project packed into one file, for sending, backups and handing to Book. |
| Wordsmith Book | `My Book.wsbk` | A book project folder: the book's settings and designs, linked to your manuscript. |
| | `My Book.wsbkz` | The same book project packed into one file. |

Because the text is plain text and Markdown, you can open it in any text editor, and nothing you
write is locked inside an app.

<Callout type="info" title="Folders that look like files">
A Manuscript or Book project is a folder whose name ends in `.wsm` or `.wsbk`. Keep the whole
folder together when you copy or move it, and open the folder itself in the app.
</Callout>

## Backups and recovery

Each app saves as you work and can recover what you were writing if it closes unexpectedly. Each
also keeps backups of its own:

- **Script** keeps backups of every script (up to 1,000 each) in a `Backups` folder in its
  settings folder. See [Script: Files](../script/files.mdx).
- **Manuscript** can save snapshots of a scene before you rewrite it, and makes backups as packed
  `.wsmz` files. See [Manuscript: Files](../manuscript/files.mdx).
- **Book** keeps a recovery copy inside the book folder. See [Book: Files](../book/files.mdx).

The apps' own backups are on the same computer as your work. For anything you care about, also
keep a copy somewhere else: an external drive, or a folder that syncs to the cloud.

<Callout type="warn" title="Synced folders">
Keeping a project in a synced folder (iCloud Drive, Dropbox, OneDrive and the like) is fine, but
only have it open on one computer at a time. If two computers change the same project at once, the
sync service can end up with two versions.
</Callout>

## Newer and older versions

Until the first releases, an app's file format can change. A newer version opens files from older
versions, but an older version may not open files saved by a newer one. If you share files with
someone, use the same version.

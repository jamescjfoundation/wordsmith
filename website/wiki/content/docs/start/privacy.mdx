Your writing stays with you. The Wordsmith apps have no accounts and send no telemetry: no usage
statistics, no crash reports, nothing about what you write or how. Your text, notes and file names
are never sent anywhere.

## The update check

The only request an app makes on its own is a check for a newer version.

- **Script and Manuscript** ask GitHub (`api.github.com`) whether a newer release exists, when the
  app starts and when you choose **Check for Updates**. Like any website, GitHub sees your IP
  address, and the request names the app and its version. Nothing else is sent.
- Nothing is downloaded unless you choose to install an update.
- **Book** makes no network requests at all today. When it gets update checks, you'll be able to
  turn them off the same way.

### Turning it off

In Script or Manuscript, open **File › Preferences** and turn off
**Check for updates when the app starts**. You can still check by hand whenever you like.

The command-line tools that come with Script and Manuscript never check for updates.

## Tools you choose to use

Some features hand a file to another program, for example a document converter you've installed
for an import or export. That only happens when you set it up yourself, and the program runs on
your own computer.

## This website and wiki

wordsmithand.ink and this wiki don't use cookies, analytics or trackers, and the fonts are served
from the site itself, so no visitor data goes to a font service. The site is hosted on GitHub
Pages.

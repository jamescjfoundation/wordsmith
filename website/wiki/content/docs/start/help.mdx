Everything about Wordsmith happens in the open on GitHub, under
[jamescjfoundation](https://github.com/jamescjfoundation).

## Report a problem or suggest an idea

Open an issue in the app's repository:

- [Wordsmith Script issues](https://github.com/jamescjfoundation/wordsmith-script/issues)
- [Wordsmith Manuscript issues](https://github.com/jamescjfoundation/wordsmith-manuscript/issues)
- [Wordsmith Book issues](https://github.com/jamescjfoundation/wordsmith-book/issues)

You'll need a free GitHub account. A good report says:

- which app, and which version (it's on the File page, under About);
- your system: macOS, Windows or Linux, and its version;
- what you did, what you expected, and what happened instead;
- a small file that shows the problem, if you can share one. Leave out anything private.

Ideas are just as welcome as bug reports. The same pages show what is already planned: each open
issue is something someone means to do or has asked for.

A security problem is not reported in an issue. Each repository's Security tab has
**Report a vulnerability**, which only the maintainers see.

## Improve a guide or this wiki

Every page has an **Edit on GitHub** link at the bottom. It opens the file the page is made from,
which is Markdown, in GitHub's editor, and GitHub walks you through proposing the change.

- **A page about one app** is that app's own guide, kept in the app's repository under
  `docs/guide/`. The link takes you there. When your change lands, this wiki is built from it
  again.
- **A page about the project as a whole**, like this one, lives in the
  [wordsmith repository](https://github.com/jamescjfoundation/wordsmith) under `website/wiki`.
  Its [CONTRIBUTING.md](https://github.com/jamescjfoundation/wordsmith/blob/main/CONTRIBUTING.md)
  has the few rules for a page. What you write there is published under the Creative Commons
  Attribution 4.0 license.
